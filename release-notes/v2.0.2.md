# CodexBridge v2.0.2

这是一个性能和后台调度补丁，重点降低手机端后台请求对 Windows 鼠标和前台应用的干扰。

## 修复

- 硬件采集和手机 Companion 现在共享同一套 Codex app-server，不再因为手机请求启动第二套 Codex 引擎。
- Codex app-server 及其子进程以低于正常优先级运行，降低后台线程刷新对前台交互的抢占。
- Companion API 的普通 JSON 响应会返回 `Connection: close` 并主动结束连接，避免 HTTP/1.1 keep-alive 线程长期堆积。
- 共享 app-server 在子进程退出后可以正常重新启动，不会因为旧进程句柄卡死。
- 补充了共享客户端生命周期、HTTP 连接关闭和子进程优先级测试。

## 手机端排查

Android 模拟器组件 `netsimd.exe` 曾持续每 5 至 7 秒连接 `127.0.0.1:8568`，短时间内堆积 35 条连接。手机端需要减少后台轮询、使用 SSE、清理并发请求并加入退避重连。

完整交接说明见 [手机端联调问题交接](../docs/phone-client-handoff-2026-10-18.md)。仓库中的 `mobile/` 和手机代码未被修改。

## 验证

- Python 单元测试：`644` 项全部通过。
- 安装版实测只启动一套 Codex app-server。
- Codex app-server 子进程优先级实测为 `BelowNormal`。
- Companion 普通 JSON 响应返回 `Connection: close`，观察期间没有连接堆积。
