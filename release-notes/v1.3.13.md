# CodexBridge v1.3.13

多设备已读同步、失败通知与旧会话回复修复版。

## 变更

- **修复在旧会话回复报“已有活跃 writer”**：手机端继续一个已存在的会话时，如果电脑端
  该会话已有活跃 writer，`thread/resume` 不再直接抛出错误，而是复用当前 writer；发送
  消息遇到 active writer 时自动改用 `turn/steer`，因此新会话和老会话回复都可用。
- **已读状态在多设备间互通**：CodexBridge 新增全局已读标记（`read-state.json`）。任一
  客户端（手机伴侣或 ESP 设备）读过一条消息后，其他在线客户端会收到 `read_state`，之后
  重连的客户端也不会再收到该消息，无需各自维护本地去重。
- **打开已完成任务后状态回落为空闲**：手机端打开 `completed` / `failed` 任务时调用
  `POST /api/companion/threads/<id>/read`，电脑端记录全局已读标记，线程列表与详情状态
  变为 `idle`，并向所有手机广播 `thread_status` 的 `idle` 事件。
- **完成 / 失败声音通知，并在任意设备读过时撤回**：手机端对 `completed` 和 `failed` 都会
  在状态栏提醒（高重要级别渠道、声音+振动）；`turn_completed` 事件新增 `read` 字段，已
  被任何设备读过的完成不再提醒，收到其他设备广播的 `idle` 时也会撤回本机尚未展示的提醒。
- 电脑端版本 1.3.13，手机端 0.2.7（versionCode 9）。

## 验证

- 增加全局已读标记持久化、旧标记不能覆盖新标记、消息已读跨设备生效的单元测试。
- 增加旧会话 `thread/resume` 遇到活跃 writer 时不报错、改走 steer 的回归测试。
- 增加手机端标记已读后向其他客户端广播 `idle`、已完成任务重连后仍显示 `idle` 的测试。
- 增加 Hub 层已读抑制其他设备未读消息、合并到统一会话的测试。
- 完整运行 Python 单元测试、Android 单元测试与 Release APK 构建。
