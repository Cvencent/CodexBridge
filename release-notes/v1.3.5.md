# CodexBridge v1.3.5

手机端体验修复版：任务状态、工作空间与打开会话时的滚动行为。

## 本次更新

### 手机端任务列表

- **状态不再一直是“空闲”**：桌面正在跑的任务会显示“运行中”。
  桌面 GUI 里执行的会话对伴侣进程不可见，因此电脑端现在会读取桌面自己写入的
  rollout 日志（`~/.codex/sessions`），用最近的写入活跃度和最后一个
  `task_started` / `task_complete` / `turn_aborted` 事件来推断状态。
- **任务卡片显示“工作空间”**：接口新增 `workspace` 字段（取工作目录名，
  同时保留完整 `cwd`），列表里一眼能看出任务属于哪个目录/项目。
- **运行中的任务排在前面**：电脑端和手机端都会把 `working` / `waiting_user`
  的任务排在列表最前面，其余按最近活跃时间排序。

### 打开会话不再从头滚到底

- 点开任务时直接定位到最后一条消息（瞬时定位，不再逐条动画滚屏）。
- 只有当你本来就在底部时才跟随新的流式输出；向上翻阅历史时会保持位置，
  右下角出现“回到底部”按钮。

### 版本

- 电脑端 `1.3.5`，手机端 `0.2.0`
  （`mobile/release/CodexBridgeMobile-0.2.0-release.apk`）。

## 兼容与升级

- 安装包支持覆盖升级，并保留 `%LOCALAPPDATA%\CodexBridge` 中的配对、语音识别和其他设置。
- 手机端可以直接覆盖安装，已保存的配对信息不会丢失。
- 便携包与安装包继续只包含 `CodexBridge.exe` 一个可执行文件。
