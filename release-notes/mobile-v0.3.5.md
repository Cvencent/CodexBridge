# CodexBridge Mobile v0.3.5

这次更新让手机端可以同时保存内网和外网地址，并根据当前网络自动选择可用线路。

## 变更

- **双地址自动切换**：设置页和配对页都可以填写内网地址、外网地址；同一 Wi-Fi 或以太网优先内网，蜂窝网络优先外网，首选线路不可用时自动回退。
- **切换不再要求重新配对**：线路变化只更新连接地址，配对令牌和安装标识保持不变。
- **反代端口保持原样**：外网入口可以继续使用 `:8080`，也可以改用与内网一致的 `:8568`；电脑返回的内部端口不会覆盖用户填写的外网代理端口。
- **后台通知跟随线路**：完成通知服务在 SSE 重连和轮询时也会重新选择内外网线路。
- **聊天页自动恢复**：Wi-Fi 与蜂窝网络切换导致连接中断时，聊天页会尝试重新选择线路并恢复事件流。
