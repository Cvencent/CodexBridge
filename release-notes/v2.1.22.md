# CodexBridge v2.1.22

这个版本为 CBDP 设备补充线程级 turn 终态事件，让设备能够按具体任务播放完成、
失败或中断提醒，不再只能从聚合计数推断。

## 修复

- **结果落库时写入终态事件。** `Hub.publish()` 处理 `kind=result` 时，按状态写入
  `turn.completed(0x0203)`、`turn.failed(0x0204)` 或
  `turn.interrupted(0x0205)`，使用该线程的 topic、`thread` scope 和
  `critical` QoS。
- **Payload 使用现有 TLV。** 包含 `THREAD_ID`、`THREAD_REF`、`TURN_ID`、
  `TURN_REF`、`KIND`、`STATUS`、`TITLE`、`SUMMARY`、`BODY`、`MESSAGE_ID` 和
  `COMPLETED_AT_MS`，设备可显示具体任务和结果正文，无需新增协议字段。
- **按 turn_id 幂等。** 同一线程同一 `turn_id` 只写一次终态事件；缺少 turn_id
  时使用稳定的结果 `message_id` 去重，collector 周期刷新不会重复提醒。
- **interrupted 结果补齐。** `records_from_snapshot()` 现在接受
  `interrupted` / `cancelled` / `canceled`，并统一映射为 `interrupted`，使
  `0x0205` 能实际产生。
- **保留聚合计数。** `system.codex_state(0x0704)` 和 summary scope 不变，继续
  用于首页运行中、已完成和失败数量徽标。
- **手机配对令牌不再因重启丢失。** `companion.json` 读取失败时失败关闭，不再
  用空内存覆盖原文件；JSON/UTF-8 损坏时先隔离备份，再从 `devices.json` 的 phone
  投影恢复记录。保存改为 fsync + 原子替换并带 Windows 重试。

## 验证

- 新增 complete / failed / interrupted 载荷测试、同 turn_id 幂等测试、
  collector interrupted 结果测试，以及损坏配对文件隔离、未加载禁止覆盖、从
  registry 恢复手机记录测试。
- 完整单元测试通过（786 项）。
