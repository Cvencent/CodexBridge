# CodexBridge v2.1.6

这个版本补齐 v2.1.5 在真机端到端验证中暴露的两处遗漏。

## 修复

- **握手响应也分配传输序号**：v2.1.5 只给 `RESULT` / `ERROR` 加了非零 `seq`，
  但 `WELCOME` 和 `AUTH_OK` 同样属于可确认帧，仍在用 `seq = 0`。现在两者也
  分配非零递增 `seq`，并 piggyback 当前的 `ack_seq`，握手阶段即可建立累计确认。
- **Companion 通道接入 `active_state`**：v2.1.5 的 `active_state.read/set`
  只在设备 TCP 网关接线，手机 Companion 通道构造网关时没有传入回调，导致
  手机侧调用 `active_state.set` 仍返回 `UNSUPPORTED_FEATURE`。现在两条通道共用
  同一套 Hub 活动状态读写。

## 验证

- 完整单元测试：`705` 项全部通过。
- 真实安装版 WebSocket 端到端：`WELCOME` / `AUTH_OK` 序号非零，
  `RESULT` 携带递增 `seq` 与非零 `ack_seq`，`active_state.read/set` 均返回
  `RESULT`，`set` 之后 `read` 能读回刚写入的线程引用。
