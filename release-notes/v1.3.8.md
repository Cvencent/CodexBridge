# CodexBridge v1.3.8

手机端远程编辑可靠性修复版。

## 修复内容

- **手机回复不再被“活跃 writer”卡住**：电脑端发送优先走新的
  `turn/start`，如果 Codex 检测到同一线程已有活跃 writer，会自动改用
  `turn/steer`；反向的“没有活跃 turn”也会自动回退。
- **已读的完成状态会归为空闲**：手机点开已完成任务后，同一线程当前这次
  完成会显示为空闲；之后产生的新完成仍会重新显示为已完成。
- **新增任务完成通知**：手机保持后台 SSE 监听，任务完成后发送 Android
  状态栏通知，点击通知可直接进入对应任务。
- **修复“运行中”状态残留**：电脑端明确返回空闲状态时，手机端不再固守
  本地旧的运行中标志。
- 电脑端版本 `1.3.8`，手机端 `0.2.2`（`versionCode 4`）。

## 验证

- 后端加入 `turn/start` 与 `turn/steer` 双向自动回退回归测试。
- 手机端加入完成已读归一、旧标记不吞掉新完成、通知去重键测试。
- 完整 Python 测试与 Android debug/release 单元测试、Release APK 构建均通过。
