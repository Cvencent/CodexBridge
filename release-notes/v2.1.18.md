# CodexBridge v2.1.18

这个版本修复事件库索引损坏导致 CBDP summary 订阅返回 `INTERNAL` 的问题。

## 修复

- **启动时校验事件库。** `EventSpine` 打开
  `%LOCALAPPDATA%\CodexBridge\cbdp-events.sqlite3` 前执行
  `PRAGMA quick_check`。健康库不会备份或改写。
- **损坏库自动无损恢复。** 检测到损坏后，先把主库和 WAL/SHM 备份为
  `cbdp-events.sqlite3.corrupt-<时间戳>`，再用 `VACUUM INTO` 重建索引并原子替换。
  重建结果会再次校验；历史事件、`global_seq`、`topic_seq` 和 `revision` 均保留。
- **恢复失败也有安全兜底。** 如果损坏严重到无法转存，Bridge 保留损坏备份并新建
  空事件库继续启动，不会删除唯一副本，也不会因事件库损坏整体启动失败。
- **订阅错误可诊断。** 运行期间若事件存储再次异常，`SUBSCRIBE` 会返回
  `INTERNAL`，并带 `error_message=EVENT_STORE_UNAVAILABLE` 和
  `reason=event_store_unavailable`，不再是无信息的兜底错误。

## 验证

- 新增健康库、损坏恢复、恢复失败兜底、WAL/SHM 替换和订阅诊断错误测试。
- 使用本机真实损坏库副本验证：`VACUUM INTO` 后 `quick_check=ok`，2041 条历史事件
  全部保留，summary 主题查询恢复正常。
- 完整单元测试通过。
