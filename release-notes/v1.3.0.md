# CodexBridge v1.3.0

这是一个语音接口兼容性与设置页可用性更新。

## 本次更新

### 语音连接测试兼容标准转写接口

- 修复连接测试把「接口可达、但探活音频没有语音」错误判定为失败的问题。
- 当兼容接口返回 `HTTP 422 no speech detected` 时，现在会正确显示连接成功。
- 其它 4xx/5xx、网络错误和鉴权失败仍会如实返回，不会被误判为可用。

### 设置中心布局

- 常规设置改为两列排列，设备与语音识别面板保持稳定的桌面网格。
- 窄屏下自动回落为单列，设备卡片减少嵌套边框，长内容不再挤压相邻面板。
- 语音识别方式选项改为响应式两列布局，移动端自动变为单列。

### 兼容范围

- 适配返回 OpenAI `POST /v1/audio/transcriptions` 形状的兼容接口，包括
  当前只能返回空结果或 `422 no speech detected` 的静音探活行为。
- 原有内置识别和远程失败自动回退逻辑保持不变。

## 下载

- `CodexBridge-Setup-1.3.0-win64.exe`：Windows 安装包，推荐使用。
- `CodexBridge-1.3.0-win64-portable.zip`：免安装便携版。

## 系统要求

- Windows 10 或 Windows 11，64 位。
- 运行核心不需要单独安装 Python。
