# CodexBridge v2.1.16

这个版本修复图片输入的真实序列化形状，图片附件现在能真正进入 Codex。

## 修复

- **图片输入变体名错误。** `v2.1.15` 使用 `{"type":"input_image","image_url":...}`，
  但 Codex app-server 的 `turn/start` 只接受
  `text` / `image` / `localImage` / `audio` / `localAudio` / `skill` / `mention`。
  现在改为正确的 `{"type":"image","url":"data:<mime>;base64,..."}`。
- 队列项因此不再以
  `unknown variant input_image, expected one of text, image, localImage...` 失败。
  手机端 `input_parts` 接口不变，无需改代码。

## 验证

- 直接对真实 app-server 发送带 `{"type":"image","url":...}` 的 `turn/start`，
  返回的是 `thread not found`（输入已通过反序列化），不再是 `unknown variant`。
- 附件与 Companion 定向测试：`33` 项通过。
