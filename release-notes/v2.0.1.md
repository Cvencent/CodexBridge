# CodexBridge v2.0.1

这是一个补丁版本，修复已批准的 ESP/硬件设备无法从管理页面删除的问题。

## 修复

- 已批准的 ESP 和其他硬件设备现在在设备列表和详情抽屉中都有“删除设备”入口。
- 删除前会明确提示：CodexBridge 会忘记当前配对记录，设备继续广播时会重新出现在待批准列表。
- 删除后，设备会在下一次 UDP 发现或主动通告时重新登记为 `pending`，不会自动沿用旧令牌。
- 重新出现的设备需要在本机管理页面再次批准，批准后建立新的配对令牌。

## 验证

- Python 单元测试：`639` 项全部通过。
- 新增删除后重新发现为 `pending` 的回归测试。
- 新增管理页面硬件删除入口和 API 接线测试。
