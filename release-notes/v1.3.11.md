# CodexBridge v1.3.11

Codex CLI 自动定位修复版。

## 变更

- **修复“未找到 Codex CLI”**：CodexBridge 现在会在 `PATH` 之外自动查找
  Codex 桌面版安装的 CLI，覆盖 `%LOCALAPPDATA%\OpenAI\Codex\bin` 以及 npm
  的常见全局安装位置。
- **保留显式配置优先级**：`CODEXBRIDGE_CODEX_COMMAND` 和
  `STATE_DISPLAY_CODEX_COMMAND` 仍然优先，只有它们不可用时才使用自动发现。
- **修复升级后启动方式变化**：从安装器或资源管理器独立启动 CodexBridge 时，
  不再依赖 Codex 桌面版临时注入到自身进程的 `PATH`。
- 电脑端版本 `1.3.11`，手机端 `0.2.5`（`versionCode 7`）。手机应用没有协议变化，
  本次 APK 会一并生成，便于保持发布版本整齐。

## 验证

- 增加 `PATH` 不包含 Codex 目录时自动定位官方 `codex.exe` 的回归测试。
- 增加显式命令优先于自动发现的测试。
- 完整运行 Python 单元测试和 Android 构建。
