# CodexBridge v2.1.28

这个版本修复设备在线/离线状态抖动与手机长期显示离线的问题。

## 修复

- **在线/离线改为边沿触发。** `device.online` / `device.offline` 只在状态真正
  变化时发布。重复清理、拨号失败和旧会话晚到的 `detach` 不再重复发离线事件。
- **增加 8 秒在线迟滞。** Wi-Fi 省电或瞬时重连造成的短暂断开会先进入宽限窗口；
  期间重新连上就不会发布 `device.offline`，避免设备列表闪断。
- **旧会话不能踢掉新会话。** 会话清理现在带 session 身份校验，旧线程晚结束时
  不会把已经接替它的新连接从 Hub 移除。
- **手机 SSE 心跳刷新在线状态。** 手机 Companion 的 SSE/WebSocket 长连接现在
  在周期心跳时刷新 `last_seen`；管理页用 120 秒在线窗口判定 HTTP 手机，手机一直
  开着时不会再因为 `last_seen` 不更新而显示离线。

## 影响

- 管理页、设备列表中在线/离线状态不再每 10–15 秒反复变化。
- 真实离线的设备仍会在宽限窗口后变为离线，不会永久显示在线。
- CBDP 线格式和事件编号不变。

## 验证

- 新增失败拨号、重复 detach、旧 session 清理、短重连迟滞和手机在线窗口测试。
- 完整单元测试通过。
