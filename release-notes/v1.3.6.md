# CodexBridge v1.3.6

升级安装修复版：确保覆盖安装会真正关闭旧版并替换可执行文件。

## 修复内容

- 安装器现在会在复制文件前强制结束旧的 `CodexBridge.exe` 进程。
  - 旧版本的托盘程序有时不会响应 Inno Setup 的自动关闭请求，导致安装器反复提示“关闭应用程序”但始终关不掉。
  - 1.3.6 改为由安装器直接执行 `taskkill /F /T /IM CodexBridge.exe`，不再依赖旧进程响应关闭消息。
- 覆盖安装仍保留 `%LOCALAPPDATA%\CodexBridge` 下的配对记录、手机令牌、语音识别配置和日志。
- 修复了发布工作流会把旧版手机 APK 一并上传的问题，后续 Release 只附带当前 `versionName` 对应的 APK。
- 电脑端版本提升到 `1.3.6`；手机端仍为 `0.2.0`，无需重新配对。

## 升级说明

- 已经遇到“安装器关不掉旧进程”的用户，直接运行 1.3.6 安装包即可完成覆盖。
- 安装完成后启动 CodexBridge，手机重新扫描局域网即可看到电脑。
- 如果手机端之前保存的是旧连接，重新扫描后选择 CodexBridge 即可；配对令牌仍保存在电脑端。
