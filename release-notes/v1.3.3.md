# CodexBridge v1.3.3

这是一个设备重连与托盘弹窗可用性修复版本。

## 本次更新

### 修复“关于”窗口无法关闭

- 修复在托盘菜单回调中直接打开模态窗口、导致 Windows 托盘消息循环被阻塞的问题。
- “关于”窗口现在会在独立线程中打开，确定按钮、关闭按钮和 Alt+F4 都可以正常工作。
- 同样的处理也应用到了“管理中心不可用”提示窗口，避免出现同类卡住问题。

### 修复设备重连后卡在项目加载

- 设备重连时，如果已经处于 Codex 项目加载状态而没有重新发送目录请求，CodexBridge 现在会主动补发一次项目目录。
- 具备 `tasks` 能力的设备可从加载状态正常进入项目列表，原有带 `request_id` 的目录请求回显逻辑保持不变。

### 兼容与升级

- 安装包和便携包继续只包含 `CodexBridge.exe` 一个可执行文件。
- 安装包支持覆盖升级，并保留 `%LOCALAPPDATA%\CodexBridge` 中的设备配对、语音识别和其他设置。

## 下载

- `CodexBridge-Setup-1.3.3-win64.exe`：Windows 安装包，推荐使用。
- `CodexBridge-1.3.3-win64-portable.zip`：免安装便携版。

## 系统要求

- Windows 10 或 Windows 11，64 位。
- 运行核心不需要单独安装 Python。
