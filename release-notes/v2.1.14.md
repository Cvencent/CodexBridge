# CodexBridge v2.1.14

这个版本修复桌面线程的设置读写，并补齐 Bridge 侧的线程设置持久化。

## 修复

- **桌面线程设置更新失败。** `thread.settings.update` 现在和 `turn.start` 一样，
  先通过桌面 IPC 做 owner discovery，再由线程真实 writer 执行设置修改。桌面创建
  的线程不会再因为 Bridge 自己的 app-server 不认识而返回 `thread not found`。
- **策略值读不回。** app-server 的 `thread/read` 不返回
  `approvalPolicy` / `sandboxPolicy` / `approvalsReviewer`。Bridge 现在把成功
  应用的策略写入 `%LOCALAPPDATA%\CodexBridge\thread-settings.json`，
  `thread.settings.read` 优先读取这份持久化镜像；上游线程不可读时仍能返回上次
  生效值，避免手机把用户选择重置成默认。
- **effort 字段兼容。** 读取设置时同时兼容 `effort` 和上游实际返回的
  `reasoningEffort`。
- **设置镜像写入更稳。** 使用唯一临时文件再原子替换，并清理残留临时文件。

## 验证

- 完整单元测试：`738` 项全部通过。
- 新增回归测试：桌面 owner discovery 的设置更新、设置镜像读取、桌面线程无上游
  readback 时的策略读取。
