# CodexBridge v2.1.17

这个版本修复设备端按项目读取任务列表，以及首页聚合计数收不到的问题。

## 修复

- **`threads.list` 支持按项目过滤。** 设备携带 `project_ref(0x0122)` 时，Bridge
  通过持久引用表解析成 `project_id`，再按该项目的根目录对线程 `cwd` 做前缀匹配。
  引用无效时返回 `NOT_FOUND`，不再返回 `INTERNAL`。
- **项目键兼容。** 解析同时支持桌面项目 `project_id` 与项目名称两种持久键，
  兼容 `projects.list` 返回的两种项目形态。
- **避免 INTERNAL 兜底。** `threads.list` 的可选参数加入 `project_id`，
  不再因未知参数落入通用异常分支。
- **订阅时补发首页计数。** 设备订阅
  `system.thread_summaries(0x50000003)` 的 `summary` scope 时，若回放窗口中没有
  `system.codex_state(0x0704)`，Bridge 会在回放结束前补发最新一条聚合计数，
  修复 attach 早于 SUBSCRIBE 导致首页计数永久为 0 的时序问题。

## 验证

- 新增 `project_ref → project_id` 解析测试（含未知引用返回 `NOT_FOUND`）。
- 新增按项目 cwd 过滤线程列表测试。
- 新增订阅帧级测试：回放窗口被摘要事件填满时，仍能收到最新 `0x0704`。
