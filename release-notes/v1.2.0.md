# CodexBridge v1.2.0

这是一个以易用性、统一配置和安装升级为核心的版本。

## 本次更新

### 托盘菜单更简洁

- 托盘右键菜单只保留「重启」「关于」「退出」三项。
- 左键单击或双击托盘图标，直接打开网页管理中心。
- 设备、能力、令牌、日志目录等设置不再散落在托盘菜单里。

### 网页管理中心

- 所有设置统一放在 `http://127.0.0.1:8788/settings`。
- 可查看设备在线状态、可用能力、配对令牌和 Codex 采集状态。
- 可逐台开启或关闭设备能力，并立即下发到在线设备。
- 新增「打开日志目录」，方便查看运行日志、录音和设备配置。

### 语音识别

- 内置识别与 OpenAI 兼容接口共用一套配置。
- OpenAI 兼容接口支持填写完整转写地址、API Key、模型和语言。
- 已保存的 API Key 不会回传到浏览器；留空表示保留原 Key，也可显式清除。
- 远程接口不可用时自动回退到内置识别。

### 开机自启动

- 新增 Windows 当前用户开机自启动开关。
- 设置从网页管理中心完成，不需要编辑启动目录或注册表。

### 安装与升级

- 安装器默认使用简体中文。
- 新版安装包覆盖安装旧版时，会沿用原安装目录、开始菜单和用户数据。
- `%LOCALAPPDATA%\CodexBridge` 下的设备、语音和其他配置都会保留。

## 下载

- `CodexBridge-Setup-1.2.0-win64.exe`：Windows 安装包，推荐使用。
- `CodexBridge-1.2.0-win64-portable.zip`：免安装便携版。

## 系统要求

- Windows 10 或 Windows 11，64 位。
- 运行核心不需要单独安装 Python。
