# CodexBridge v1.4.3

手机和 ESP 等已配对设备默认只看对话与最终回答，中间命令、结果和思考过程由电脑端统一隐藏。

## 变更

- **新增“显示中间事件”全局配置**：管理中心可以在“手机连接”区域切换。默认关闭，对所有已配对设备生效。
- **协议层隐藏中间事件**：关闭时，电脑端会过滤思考过程、进度说明、命令、文件变更、工具调用、计划和上下文提示，只返回用户消息、最终回答以及必要的审批和错误通知。过滤同时覆盖历史读取和实时事件流，因此手机和 ESP 设备都不会收到这些内容。
- **保留完整模式**：需要排查问题时，可以在管理中心开启“显示中间事件”，恢复原来的完整事件输出。
- `/api/companion/status` 现在返回 `show_intermediate_events`，通用客户端可以读取当前策略。
- 电脑端 1.4.3，手机端保持 0.3.1（versionCode 17）。这次过滤在电脑端协议层完成，手机端无需重新安装即可获得默认隐藏效果。

## 说明

- 配置保存在电脑端的 `companion.json`。旧配置没有这个字段时会自动按“关闭”处理。
- 这是一个全局设置，手机、ESP 和其他使用同一 companion 协议的设备都会遵循。

## 验证

- Python 单元测试 350 项全部通过。
- Android 单元测试 17 项通过。
- 验证了历史读取和实时事件流都会遵守中间事件开关。
