# CodexBridge v1.3.2

这是一个架构合并版本：CodexBridge 与 Dotii 管理中心合并为一个可执行文件和一个托盘图标。

## 本次更新

### 单文件、单托盘

- 安装包和便携包现在只包含 `CodexBridge.exe` 一个可执行文件。
- Dotii 管理中心作为隐藏子进程由 CodexBridge 托盘宿主托管，不再单独启动 VBS 或第二个程序。
- 子进程异常退出时自动重启，多次异常后停止重启并给出提示。
- 托盘菜单新增“打开管理中心”，并保留设备能力开关、打开设置、重启、关于、退出。

### 固件与烧录

- 固件包和 esptool 已内置进 EXE，刷写 Dotii 固件不再需要安装 Python。
- 修复了无控制台窗口时 `--esptool` 转发因退出码为空而挂死、导致固件包检查超时的问题。

### 统一协议

- 沿用同一套设备协议和管理接口：UDP 发现 `8764`、设备 TCP `8765`、CodexBridge 管理接口 `8788`、Dotii 管理中心 `8787`。
- 没有引入新的协议版本，Dotii 设备继续按现有协议接入。

## 下载

- `CodexBridge-Setup-1.3.2-win64.exe`：Windows 安装包，推荐使用。
- `CodexBridge-1.3.2-win64-portable.zip`：免安装便携版。

## 系统要求

- Windows 10 或 Windows 11，64 位。
- 运行核心不需要单独安装 Python。
