# CodexBridge v1.1.0

这是 CodexBridge 的第一个 Windows 安装包版本，也是网页管理中心和共享语音识别的首个正式版本。

## 本次更新

### Windows 安装包

- 新增 Inno Setup 安装器，提供简体中文安装界面。
- 新增便携 ZIP 包。
- 安装包和便携包都会在打标签时由 GitHub Actions 自动构建并上传。

### 网页管理中心

- 新增本机设置页面：`http://127.0.0.1:8788/settings`。
- 可查看设备列表、设备型号、在线状态和可用能力。
- 可保存每台设备的启用能力，并生成配对令牌。
- 可查看 Codex 采集器状态。

### 设备与消息

- 统一 Dotii 与 AI Passport 的发现、握手、能力和消息协议。
- 支持按设备能力过滤消息，避免向设备发送未授权内容。
- 支持消息补发和多设备已读状态同步。
- 支持从旧 `%LOCALAPPDATA%\FoloOS\bridge.json` 迁移设备信息。

### 语音识别

- 新增共享语音识别服务，Dotii 与 AI Passport 使用同一份配置。
- 支持内置离线识别，优先使用 Vosk 模型，失败时回退 Windows `System.Speech`。
- 支持 OpenAI 兼容的转写接口，可填写接口地址、API Key、模型和语言。

## 下载

- `CodexBridge-Setup-1.1.0-win64.exe`：Windows 安装包，推荐使用。
- `CodexBridge-1.1.0-win64-portable.zip`：免安装便携版。

## 系统要求

- Windows 10 或 Windows 11，64 位。
- 运行核心不需要单独安装 Python。
