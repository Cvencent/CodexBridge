# CodexBridge v2.1.10

这个版本修复 v2.1.9 暴露的一个订阅回放缺陷，它是首页计数事件真正到达设备的前提。

## 修复

- **新订阅者的回放窗口**：`SUBSCRIBE` 不携带 `cursor` 时，Bridge 会从
  `global_seq = 0` 开始回放。事件日志已有两万多条时，设备只能拿到**最旧的**
  一页，永远到不了当前状态，因此 `system.codex_state` 这类“当前状态”事件
  实际上不会到达。
- 现在没有 cursor 的新订阅者会收到**最新的**有界窗口（按 `queue_depth` 限流，
  仍按 `global_seq` 升序发送），带真实 cursor 的订阅仍从该 cursor 之后精确续传。

## 验证

- 完整单元测试：`726` 项全部通过。
- 新增回归测试：长日志上新订阅只回放最新窗口且顺序升序、cursor 为最新事件、
  带 cursor 的续传行为不变。
