# CodexBridge v1.3.4

这是一个“手机远程控制 Codex”版本，同时把手机端 Android 应用并入本仓库的 `mobile/` 目录。

## 本次更新

### 手机伴侣接口（新功能）

- 电脑端新增伴侣接口（默认端口 `8790`，管理页面可关闭），同一局域网内的手机可直接查看
  Codex 线程、读取完整消息流、继续对话、切换模型、新建任务并处理审批。
- 手机通过 UDP `8766` 自动发现电脑，也可以手动填写 `http://<电脑 IP>:8790`。
- 管理页面 `http://127.0.0.1:8788/settings` 新增“手机连接”面板：启用开关、局域网地址、
  一次性 6 位配对码（10 分钟有效）以及已配对手机列表。
- 配对令牌由电脑端签发、只保存在手机与电脑本机；接口仅面向局域网。
- 接口细节见 `PROTOCOL.md` 第 17 节。

### Android 手机端应用

- 新增 `mobile/` 目录：Kotlin + Jetpack Compose 应用，APK 见
  `mobile/release/CodexBridgeMobile-0.1.0-release.apk`。
- 支持任务列表与搜索、完整消息流、流式输出、模型切换、新建任务、审批处理、
  账号额度查看与深色主题。
- 手机端版本单独打 Tag：`mobile-v0.1.0`。

### 修复手机端无法发送消息

- 修复 app-server 重启后手机发送消息返回 HTTP 503 `thread not found` 的问题。
- 发送、改向和中断前会先按线程 ID `thread/resume`，把磁盘上的历史线程加载进当前
  app-server；客户端重建时会清空恢复缓存。

### 修复手机新建任务被拒绝

- 修复手机端新建任务时把项目路径当成模型名发送的问题（`(cwd, model)` 参数顺序错误
  导致桌面端拒绝创建）。

## 兼容与升级

- 安装包支持覆盖升级，并保留 `%LOCALAPPDATA%\CodexBridge` 中的配对、语音识别和其他设置。
- 便携包与安装包继续只包含 `CodexBridge.exe` 一个可执行文件。

## 下载

- `CodexBridge-Setup-1.3.4-win64.exe`：Windows 安装包，推荐使用。
- `CodexBridge-1.3.4-win64-portable.zip`：免安装便携版。
- `CodexBridgeMobile-0.1.0-release.apk`：Android 手机端（见 `mobile/release/`）。

## 系统要求

- Windows 10 或 Windows 11，64 位。
- Android 8.0 及以上（手机端）。
