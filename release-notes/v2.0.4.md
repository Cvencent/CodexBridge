# CodexBridge v2.0.4

这个版本把 CBDP v1 正式接到手机 Companion 端口，落实手机端交接文档里的 Bridge 侧缺口。

## 新增

- `8568` 端口新增 CBDP v1 传输：
  - `GET /cbdp/v1/ws` WebSocket binary
  - `GET /cbdp/v1/events` HTTP + SSE
  - `POST /cbdp/v1/frame` HTTP 反向通道
- 三条路径复用同一套 `CbdpGateway`、事件主链、订阅管理器、writer lease 和引用注册表。
- CBDP 会话复用手机配对凭据作为 HMAC key，HELLO/WELCOME 后即可直接订阅和发命令。
- SSE 的 `id:` 使用帧 cursor（DELTA 的 `global_seq`），重连时可用 `Last-Event-ID` 作为 resync cursor。
- 管理接口 `GET /api/admin/companion` 新增 `cbdp_v1` 声明，包含协议版本、路径、鉴权方式、端口和启用状态。

## 修复

- Companion 停止时会主动结束已打开的 SSE/WS 连接，不再等 TCP 超时。
- SSE 循环改为 1 秒切片等待，心跳仍按 15 秒发送，停止能在约 1 秒内生效。

## 验收

- 完整单元测试：`655` 项全部通过。
- 真实端到端验证：在 `8568` 上 `POST /cbdp/v1/frame` 收到 `202`，SSE 收到 `WELCOME`，AUTH 后收到 `AUTH_OK`。
- 新增 10 项 CBDP HTTP 传输测试，覆盖鉴权、握手、cursor、停止清理和路径声明。

## 文档

- `docs/CBDP-V1-PROTOCOL.md` 3.1.1 节记录手机 Companion 端口上的 CBDP 鉴权与传输语义，标注为“v1.0 实现后追加”，供手机端按此实现。
