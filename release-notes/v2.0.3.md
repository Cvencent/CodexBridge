# CodexBridge v2.0.3

这是一个补丁版本，进一步降低手机和硬件后台刷新对 Windows 前台交互的影响。

## 修复

- 在共享 Codex app-server 内增加只读请求合并。相同参数的 `thread/list`、`thread/read`、模型、项目、账户等读取在 10 秒内只执行一次。
- 采集器和手机 Companion 不再在同一时间段重复触发相同的完整线程读取。
- 写操作、审批响应和 app-server 重连会立即清理只读缓存，避免使用过期状态。
- 保持单一 Codex app-server、低于正常优先级和 Companion 响应主动断开连接的配置。

## 验证

- Python 单元测试：`645` 项全部通过。
- 安装版 30 秒采样中，Codex app-server 从每 5 秒约 `2` 秒 CPU 降至 30 秒仅一次 `1` 秒 CPU。
- Companion `8568` 连接未出现堆积。
- Codex app-server 始终只有一套，优先级为 `BelowNormal`。

## 手机端问题

- 手机端联调问题仍按 [手机端联调问题交接](../docs/phone-client-handoff-2026-10-18.md) 处理。
- 本版本未修改 `mobile/` 或任何手机端代码。
