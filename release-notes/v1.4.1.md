# CodexBridge v1.4.1

Windows 安装记录自动与程序本体对齐版。

## 变更

- **Windows"应用和功能"版本号自愈**：Inno Setup 只在安装流程的最后一步写卸载注册表。
  升级向导如果中途被打断（窗口被关闭、进程被结束、杀毒软件拦截等），会出现"程序文件
  已经是新版、Windows 里显示的版本和安装日期还是旧版"的情况。现在打包版每次启动都会
  检查自己的卸载记录，发现版本不一致就用当前运行版本、当天日期和主次版本号修正它，
  不需要再重装一次。
- **覆盖两种安装方式**：非管理员安装（当前用户注册表里的 `_is1` 键）和机器级安装
  （HKLM）都会修正；权限不足时静默跳过，不影响启动。便携版在本机没有安装记录时不做
  任何事。
- 电脑端版本 1.4.1。手机端保持 0.3.0（versionCode 16），无需重新安装。

## 说明

- 单独运行便携包不会产生或修改安装记录；只有确实存在安装记录的机器才会被修正。
- 若升级包本身完整跑完，安装器写入的值和自愈写入的值一致，两者不冲突。

## 验证

- Python 单元测试 339 项全部通过，新增 6 项自愈逻辑测试（记录缺失、版本一致、旧版本、
  缺 DisplayVersion、机器级写入被拒、无后缀旧键）与 1 项安装脚本 AppId 一致性测试。
- 在真实 Windows 注册表上复现用户遇到的状态（文件为 1.4.0、记录为 1.3.7 与 10 月 14 日），
  运行修复逻辑后恢复为运行版本与当天日期。
- 用 1.4.1 安装包执行了一次真实的静默升级：安装完成后系统记录为 1.4.1；随后把记录人为
  改回 1.3.7，启动打包版应用，记录被自动修正回 1.4.1，`/api/companion/ping` 同时返回
  1.4.1，端口 8568/8569 正常。
