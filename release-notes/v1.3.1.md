# CodexBridge v1.3.1

这是一个设置管理中心页面布局修复版本。

## 本次更新

### 设置中心布局整理

- 桌面端将“常规设置”和“语音识别”排列在左侧，“设备”面板放在右侧并纵向铺满。
- 修复页面中零散空白块、面板底边不齐和视觉重心分散的问题。
- 窄屏端自动切换为单列，按照“常规设置、设备、语音识别”的顺序排列。
- 保留设备卡片、常规设置双列和语音选项响应式布局，长内容不会挤压相邻面板。

### 兼容与升级

- 安装包继续支持在旧版本上直接升级。
- 升级后会保留 `%LOCALAPPDATA%\CodexBridge` 中的设备配对、语音识别和其他设置。

## 下载

- `CodexBridge-Setup-1.3.1-win64.exe`：Windows 安装包，推荐使用。
- `CodexBridge-1.3.1-win64-portable.zip`：免安装便携版。

## 系统要求

- Windows 10 或 Windows 11，64 位。
- 运行核心不需要单独安装 Python。
