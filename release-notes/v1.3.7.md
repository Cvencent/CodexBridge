# CodexBridge v1.3.7

手机局域网扫描可靠性修复版。

## 修复内容

- **电脑端发现服务会自动恢复**：升级时如果旧进程短暂占用 UDP 8766，
  新进程不再永久退出，而是每秒重试绑定，手机扫描无需重启电脑端。
- **手机端不再依赖单次全网广播**：改为枚举 Wi-Fi 子网并定向广播，同时重复发送，
  适配小米/Android 的广播限制和路由器的广播隔离策略。
- **保留手动连接**：自动扫描仍无结果时，可以直接填写电脑地址。
- **配对记录不再被旧实例覆盖**：伴侣状态在每次修改前重新读取磁盘，
  避免升级期间并存的旧托盘进程用空列表覆盖刚配对的手机令牌。
- 电脑端版本 `1.3.7`，手机端 `0.2.1`。
