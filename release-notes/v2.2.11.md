# CodexBridge v2.2.11

这个版本为手机配对增加稳定的 Bridge 实例码，解决电脑换 IP 后手机误报“令牌配对失败”。

## 根因

Bridge 的令牌鉴权只校验 Bearer token，不依赖 IP。手机端之前把 `baseUrl`（IP +
端口）当成持久连接身份；电脑从 `192.168.0.47` 换成 `192.168.0.49` 后仍请求旧
地址，旧地址返回 `401` 时就显示成配对失败。

## Bridge 侧修复

- `companion.json` 持久化 32 位十六进制 `bridge_instance_id`。
- 派生稳定设备码 `device_id = bridge-<12位>`。
- 手机 UDP 发现、`/api/companion/ping`、配对响应和管理状态都返回这两个字段。
- 旧 `companion.json` 没有实例码时，启动自动生成并写回；以后 IP/端口变化都不变。
- 令牌鉴权仍与 IP 无关，原配对记录和 token 保留。

## 手机端还需要接入

Bridge 只能提供稳定身份；手机端必须按 `bridge_instance_id` 匹配已配对 Bridge，
在 IP/端口变化后更新连接地址并继续使用原 token。详细交接见：

`docs/CodexBridgeMobile-bridge-identity-ip-change-2026-10-26.md`

## 验证

- 实例码首次生成后跨重启保持不变。
- 旧版配对文件自动补写实例码。
- 发现、ping、配对响应和管理接口都返回同一实例码。
- 全量单元测试通过。
