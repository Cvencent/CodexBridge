# CodexBridge v2.1.15

这个版本首次实现附件与图片上传链路，手机端可以上传图片并随消息发送给 Codex。

## 新增

- **附件内容存储。** 新增 `%LOCALAPPDATA%\CodexBridge\attachments\` 持久化内容库，
  记录线程、类型、文件名、MIME、大小、SHA-256 和内容引用。
- **分片上传事务。** 实现 `attachment.upload.begin/chunk/end/cancel`，支持按
  `upload_offset` 续传、SHA-256 校验和大小上限校验。
- **图片随消息发送。** `turn.start` / `queue.add` 支持 `input_parts`，图片附件
  会转换成 Codex 的 `input_image` 内联 data URL 输入，文本与图片保持顺序。
- **Companion HTTP 接口。** 新增上传、列表、读取和删除接口，手机端接入文档见
  [CodexBridge 手机端附件接入说明](docs/CodexBridge-mobile-attachment-api.md)。
- **CBDP 设备方法。** 落地 `attachment.add/list/remove`（`0x0060..0x0062`）、
  `attachment.upload.begin/chunk/end/cancel`（`0x0063..0x0066`）和
  `content.read`（`0x00C1`）。

## 限制

- 单个附件上限 32 MiB，单分片上限 2 MiB。
- 每个线程只保留最近 64 个附件，超出后淘汰最旧的。
- 只有图片类型的附件会直接送入 Codex 模型；其它类型仍保存在内容库并可通过
  `content.read` 读取，但不会作为模型输入。

## 验证

- 完整单元测试：`744` 项全部通过。
- 端到端用例：上传 PNG → 发送带 `input_parts` 的消息 → Bridge 生成
  `input_image` 内联输入 → 附件列表可读。
