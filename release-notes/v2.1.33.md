# CodexBridge v2.1.33

这个版本修复 CodexBridge 保持设备连接时，电脑仍然间歇卡顿的问题。

## 修复

- **线程监视器不再重复解析未变化的 rollout 日志。** `CompanionService._thread_log()`
  原来只按 `8` 秒时间窗缓存，窗口一过就对每一行重新读取 `128 KB` 日志尾部并逐行
  `json.loads`；线程列表一次最多扫 `80` 行，等于每 `8` 秒重新读取并解析约 `10 MB`
  日志。CPython 的 `json.loads` 全程持有 GIL，这段时间进程内所有线程（包括给手机
  回包的 HTTP 线程）都会停摆。
  现在额外记录日志文件的 `mtime` 与大小，文件没有追加就直接复用上一次结论，
  不再读取和解析。
- **配合 v2.1.32 的桌面 IPC 解析预算**，两条主要 GIL 阻塞路径都已收敛。

## 影响

- 设备保持连接、Codex 正在输出时，电脑的滚动、拖动与点击不再出现成片卡顿。
- 线程状态仍然及时刷新：日志一旦追加，标记随之变化并立即重新读取。

## 验证

- 完整单元测试通过（819 项）。
- 实测输入延迟：修复前 `12%–38%` 的输入事件慢于 `50 ms`、最大 `1007 ms`；
  v2.1.32 降到 `6%`；本版本进一步消除未变化日志的重复解析。
