# CodexBridge v2.0.5

这个版本修复 ESP 侧反馈的 CBDP 上行互通问题，重点是文本回复无反馈、音频上行失败和读取背压。

## 修复

- **文本回复绑定活动会话**：`SEND_BEGIN / SEND_CHUNK / SEND_END` 现在把设备当前选中的会话写入 `turn.start`。
- **无会话时明确报错**：设备未选择会话时返回 `ERROR(INVALID_STATE, NO_ACTIVE_THREAD)`，不再既不创建 turn 也不回复，避免设备停在“正在发送到电脑端”。
- **实现 CBDP 音频事务**：`AUDIO_BEGIN / AUDIO_CHUNK / AUDIO_END` 从原来的 `UNSUPPORTED_FEATURE` 改为真正组装 PCM、执行 STT，并按文本回复语义提交 turn，`RESULT` 携带 `transcript`。
- **读取循环不再被阻塞**：`COMMAND`、`SEND_END`、`AUDIO_END` 的上游 Codex / STT 调用改由每设备工作线程执行，socket 读循环持续排空音频分片和心跳。
- **音频边界校验**：按 `max_audio_bytes` 限制累积，超限返回 `PAYLOAD_TOO_LARGE`；`offset` 不连续返回 `INVALID_PARAM`。
- **能力门控**：`AUDIO_BEGIN` 需要 `audio` 能力，未启用返回 `CAPABILITY_NOT_ENABLED`。

## 验证

- 完整单元测试：`659` 项全部通过。
- 新增 CBDP 音频事务测试：PCM 组装、STT、`turn.start` 提交、`RESULT(transcript)`。
- 新增延迟执行测试：设备读线程只解析帧，上游调用在工作线程执行。
- 新增无活动会话错误测试：返回结构化 `ERROR`。
