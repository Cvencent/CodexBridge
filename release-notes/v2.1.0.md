# CodexBridge v2.1.0

这个版本是 CBDP v1 的协议一致性大版本更新，集中修复 Bridge 与手机端、ESP 端联调暴露
的线协议错误，并补齐 Companion 端口的 CBDP 能力发现与对象结果编码。

## 重点修复

- **音频 TLV 编号错位（必须修）**：Bridge 的 `codec / sample_rate / channels /
  bits_per_sample / duration_ms / transcript / sha256 / audio_format` 整段编号比协议
  少一位，`sha256` 还错误地落在了 `retransmit_timeout_ms (0x00B8)` 上。现已按
  `0x0073..0x007A` 校正，`total_bytes` 回到 `0x0047`、`offset` 回到 `0x0048`。
  这会让设备上报的音频格式被解析成错误字段，也让手机端读不到 `transcript`。
- **`objects` 数组缺少 `u16` 计数前缀**：`threads.list`、`thread.read`、`models.list`、
  `projects.list`、`approvals.list` 的 `objects` 现在按 8.12 编码为
  `u16 count` + `object` 元素。此前手机端解析出来永远是空列表。
- **对象字段补全**：`thread` 对象带 `thread_ref / thread_id / title / status /
  owner_state` 及可用的 `model_name / cwd / summary / updated_at_ms`；`message`
  对象带 `message_ref / thread_ref / turn_ref / message_id / kind / status / body /
  created_at_ms`；`model` 对象带 `model_capabilities`；`approval` 对象带
  `approval_ref / thread_ref / turn_ref / approval_kind / prompt / expires_at_ms`。
- **`next_cursor` 可逆映射**：上游 app-server 返回的是不透明字符串游标，Bridge 现在
  在会话内映射为稳定的 u64 并支持回传还原，分页不会再断在第二页。
- **线程选择器**：`SEND_BEGIN` / `AUDIO_BEGIN` 支持 `thread_ref`、`thread_id` 和
  `use_active_thread`，显式指定优先于 Bridge 当前选中的会话。
- **上行完整性校验**：`SEND_END` / `AUDIO_END` 携带 `total_bytes` 或 `sha256` 时，
  Bridge 会校验实际接收的字节数与摘要，不一致返回 `INVALID_PARAM`。
- **Companion 端口能力发现**：`GET /cbdp/v1` 返回 CBDP 能力对象，
  `GET /api/companion/ping` 同时带 `cbdp_v1` 字段，手机端不需要再用 `401/404` 探测。
- **鉴权语义澄清**：Companion 端口先做 HTTP Bearer 鉴权，会话内仍然执行标准
  `HELLO -> WELCOME -> AUTH -> AUTH_OK`，两层缺一不可。
- **事务生命周期健壮性**：新连接会清理上一连接遗留的 `SEND_*` / `AUDIO_*` 事务；
  同一个 `tx_id` + `idem` 在还没有收到 payload 时重发 `BEGIN` 会被接受，不再
  永久返回 `IDEMPOTENCY_CONFLICT`。这直接缓解了设备端音频 `tx_id` 不递增导致的
  “第一段录音之后再也发不出音频”问题。
- **`status.read` 输出 `online`**：按 17.1.1 从上游连接状态投影出顶层 `online`。
- **`thread.read` 顶层字段**：RESULT 顶层携带 `thread_ref`、`thread_id`、`status`。

## 协议文档

- `docs/CBDP-V1-PROTOCOL.md` 新增 19.6 节，逐条标注 v1.0 实现后必须修正的编号、
  数组编码、游标、选择器与鉴权语义，供手机端和 ESP 端核对。

## 验证

- 新增回归测试覆盖：objects 计数前缀、opaque cursor 往返、音频 TLV 编号、真实
  `kind` 映射、显式线程选择器、`total_bytes` 不一致拒绝、`online` 投影、
  会话重建清理事务、`BEGIN` 重试接受。
- 完整单元测试：`673` 项全部通过。
