# CodexBridge v1.3.14

手机列表刷新可见、已读状态回落与旧会话续写修复版。

## 变更

- **列表刷新可见**：手机任务列表自动刷新间隔从 4 秒缩短到 2 秒；刷新时顶部刷新按钮
  变为加载指示器、列表上方显示“正在刷新…”，同步完成后显示“已同步 · 刚刚 / N 秒前”，
  不再需要猜测是否刷新过。
- **打开已完成任务后列表状态回落为空闲**：电脑端线程列表的行不携带 turns，之前
  `completed_at` 恒为 0，导致已读判断永远无法命中。现在从 rollout 日志推导完成时间戳，
  手机打开 `completed` / `failed` 任务标记已读后，列表和详情都会回落为 `idle`，并向所有
  在线客户端广播 `thread_status` 的 `idle`。
- **修复在旧会话回复报 `thread not found`**：电脑端 Codex 正占用该线程时，app-server 拒绝
  第二个 writer，`thread/resume` 报“已有活跃 writer”，`turn/start` 只返回模糊的
  `thread not found`。CodexBridge 现在对该线程执行一次 `thread/fork`，在新的线程 id 上
  承接完整历史继续对话，映射持久化到 `fork-map.json` 并在重启后复用；手机始终看到原来的
  线程 id 与历史，响应新增 `continued_as` 字段用于提示“已在同历史的副本中继续”。
- **追加消息（steer）修正**：`turn/steer` 现在携带进行中的 `expectedTurnId`，没有进行中的
  对话时返回明确中文错误，不再静默失败。
- 电脑端版本 1.3.14，手机端 0.2.8（versionCode 10）。

## 验证

- 增加线程列表依据 rollout 完成时间戳回落 `idle` 的测试。
- 增加线程被占用时 fork 续写、复用同一 fork、fork 失败返回可读错误的测试。
- 增加 fork 映射持久化、fork 事件与详情映射回源线程 id、列表不重复显示隐藏 fork 的测试。
- 增加 `turn/steer` 需要 `expectedTurnId` 的测试。
- 完整运行 Python 单元测试、Android 单元测试与 Release APK 构建。
