# CodexBridge v2.1.26

这个版本修复手机端切换桌面线程审批模式时的 sandbox 策略编码错误。

## 修复

- **桌面 IPC 改用内部标记枚举对象。** `thread.settings.update` 现在向桌面
  Codex 发送 `{"type":"dangerFullAccess"}` 等对象，不再发送
  `"danger-full-access"` 字符串，符合 `SandboxPolicyDeserialize` 的要求。
- **保留已经标准化的对象。** 如果调用方已经传入带 `type` 的对象，Bridge
  会原样转发，避免重复转换。
- **手机端无需改动。** 本次只修正 Bridge 到桌面 Codex 的私有 IPC 请求形状，
  CBDP 命令、字段和设备侧接口保持不变。

## 影响

- 手机端切换只读、工作区写入、完全访问三种审批模式时，不再因 sandbox
  策略类型错误返回 `desktop_unavailable`。
- 桌面线程的设置更新继续通过已发现的桌面 owner 路由。

## 验证

- 更新桌面 IPC sandbox 策略回归测试，覆盖字符串输入和已标准化对象两种路径。
- 运行完整单元测试。
