# CodexBridge v2.1.21

这个版本修复手机回复桌面活跃会话时，消息只在 rollout 里写入、桌面端看不到，
且回复流式中途停止的问题。

## 修复

- **生产环境恢复桌面 owner discovery。** `CompanionService` 原来只要注入
  `client_factory` 就跳过 DesktopIPC，而生产构造始终注入共享 app-server，导致
  `_desktop_owner()` 永远返回 `None`。手机回复桌面活跃会话时因此落到 Bridge
  自己的 app-server，和桌面 Codex 的 writer 竞争。
- **新增显式 `isolated` 开关。** 只有测试或嵌入式调用显式传
  `isolated=True` 时才跳过 DesktopIPC；生产默认执行桌面 owner discovery，手机
  回复通过桌面 Codex 的 `thread-follower-start-turn` 进入同一个 writer。
- 桌面端现在能实时看到手机输入和 Codex 回复；手机流式回复不再被第二套
  app-server 中断。
- `poll_thread_changes()` 的桌面发现门禁同步改为基于 `isolated`，不再依赖
  `client_factory` 是否为空。

## 验证

- 新增回归测试：隔离模式不连接 DesktopIPC；生产默认会创建 DesktopIPC 并完成
  owner discovery；桌面活跃线程的 owner discovery 仍优先于本地 app-server。
- 完整单元测试通过。
